# Plan Index

`plan/` is the single source of truth for implementation details, phased work, carry-forward notes, and readiness gates.

Rules:
- keep roadmap-level direction in `ROADMAP.md`
- keep phase execution detail under `plan/phase-*`
- when a phase closes, create the next phase folder immediately
- if something should be addressed in the next phase, record it as notes inside that next phase folder
- do not split implementation detail across parallel `docs/` trees
